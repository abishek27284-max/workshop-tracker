# Workshop Equipment Tracker (Spring Boot + HTML/CSS/JS)

## Prerequisites
- Java 17 or newer
- Apache Maven

## How to Run
1. Open a terminal in the `workshop-tracker` directory.
2. Run:
   ```bash
   mvn spring-boot:run
   ```
3. Open `http://localhost:8080` in your browser.
4. Optional H2 Database Console: `http://localhost:8080/h2-console` (JDBC URL: `jdbc:h2:mem:workshopdb`, User: `sa`, Password: empty).
